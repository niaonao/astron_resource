# astron_resource

此仓库用于收集、整理和共享与人工智能相关的资源（模型、数据集、论文、工具等）。

目录结构（初始）

- resources/                # AI 资源存放根目录
  - models/                 # 预训练模型、权重、模型卡等
  - datasets/               # 数据集说明与下载链接
  - papers/                 # 论文摘要与链接
  - tools/                  # 实用工具、脚本与指南

如何贡献

1. 在对应子目录中新增资源并完善 README 或者 index.json 条目。
2. 提交清晰的描述（资源名称、类别、链接、简短说明、许可证）。
3. 遵守仓库许可和第三方资源许可。

示例：在 resources/models/ 中新增一个模型文件夹，包含 model-card.md 和下载链接或指向外部仓库的说明。

许可证

请在提交第三方资源时注明来源和许可信息。
